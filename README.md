I'm a photographer and videographer. I make fashion, portrait and editorial work, then build the websites that hold it.

## About

My work moves between still image, short-form video and web design. I care about how a photograph is cropped, sequenced and given space on screen.

Photography came first. Code became a way to control the presentation instead of fitting the work into a ready-made portfolio theme.

## Learning

I completed several programming courses covering HTML, CSS, JavaScript and practical web development. I'm currently studying design, with a focus on typography, composition, visual identity and interface design.
