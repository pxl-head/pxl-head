I'm a photographer and videographer working in fashion, portraiture and editorial imagery. I also design and build the websites that present my work.

## About

My practice spans photography, short-form video and web design. I pay close attention to how images are framed, sequenced and given room on screen.

Photography came first. Learning to code gave me control over how the work is presented, without relying on a ready-made portfolio theme.

## Learning

I have completed several programming courses in HTML, CSS, JavaScript and practical web development. I'm now studying design, with a focus on typography, composition, visual identity and interface design.
